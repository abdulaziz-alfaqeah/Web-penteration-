Professional Recon Pipeline

Integrated 8-step workflow

Passive Subdomain Enumeration

Use subfinder to collect subdomains without touching the target.

subfinder -d target.com -all -silent | tee subs.txt

Live Host Validation

httpx verifies live hosts, status codes, tech stack, and titles.

cat subs.txt | httpx -silent -sc -title -tech-detect -o live.txt

Smart Crawling

Katana with headless browser + JS parsing to collect every URL.

katana -list live.txt -jc -kf all -d 3 -silent -o urls.txt

Directory & File Discovery

Feroxbuster with auto-recursion and sensitive extensions.

feroxbuster -u https://target.com \
  -w raft-medium-directories.txt \
  -x php,html,json,bak,old,zip,sql \
  --depth 3 -k -o dirs.txt

Hidden Parameter Discovery

x8 hunts for parameters in GET, POST, and JSON bodies.

cat urls.txt | x8 -w params.txt --reflected-only -o params.txt

Backup File Discovery

Fuzzuli specializes in smart backup file detection.

fuzzuli -url https://target.com \
  -ext zip,tar.gz,sql,rar,7z,bak \
  -o backups.txt

API Endpoint Discovery

Kiterunner with API-focused wordlists.

kr scan https://api.target.com \
  -w routes-large.kite \
  -x 20 -o api.txt

Comprehensive Vulnerability Scanning

Nuclei + Dalfox for the final sweep.

# CVEs + Exposures
cat urls.txt | nuclei -t cves/,exposures/,misconfiguration/ \
  -severity critical,high,medium -o vulns.txt

# XSS
cat urls.txt | dalfox pipe --blind https://your.xsshunter.com

Feroxbuster

Fastest auto-recursive fuzzer, written in Rust

Feroxbuster v2.11+

RustAuto-Recursion

A modern fuzzing tool combining Rust performance with smart auto-recursion. Discovers paths, extracts links from pages, and works with any wordlist.

1 Installation
# Via Cargo (fastest)
cargo install feroxbuster

# Via apt (Kali/Ubuntu)
sudo apt install feroxbuster

# Official install script
curl -sL https://raw.githubusercontent.com/epi052/feroxbuster/main/install-nix.sh | bash
2 Basic Usage

Basic scan with auto-recursion into discovered directories.

feroxbuster -u https://target.com \
  -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt \
  -t 50 -k --depth 3
3 Backup File Hunting
feroxbuster -u https://target.com \
  -w CommonBackupFileNames.txt \
  -x bak,old,backup,zip,tar,gz,sql,save,swp,orig,~,conf,env,log \
  -C 404,400 -k
4 Advanced Filtering (Soft 404)
feroxbuster -u https://target.com \
  -w wordlist.txt \
  -C 404,403,400 \
  -S 1234 -W 50 -L 10
-S size · -W words · -L lines
5 With Cookies + Proxy
feroxbuster -u https://target.com \
  -w wordlist.txt \
  -b "session=abc123" \
  -H "Authorization: Bearer xxx" \
  -p http://127.0.0.1:8080
6 WAF Evasion
feroxbuster -u https://target.com \
  -w wordlist.txt \
  --rate-limit 20 -t 10 \
  -A --timeout 10
7 JSON Reports
feroxbuster -u https://target.com \
  -w wordlist.txt \
  --json -o report.json
8 Option Table
OptionPurpose
-uTarget URL
-wWordlist
-tThreads
-xExtensions
-CExclude status codes
-S / -W / -LExclude size / words / lines
-bCookies
-HHeaders
-pProxy
-kIgnore SSL
--depthRecursion depth
--rate-limitRequests per second
-ARandom User-Agent
💡 Tip: Feroxbuster outperforms Gobuster in auto-recursion and link extraction. Use it as your default.

Spray

Smart fuzzer with auto-calibration for soft-404

Spray v1.0+

GoAuto-Calibration

A modern tool from the chainreactors team. Its standout feature is intelligent automatic filtering of fake responses (soft 404) — perfect for sites that return 200 on every path.

1 Installation
# Via go install
go install github.com/chainreactors/spray@latest

# Or ready-made release binaries
wget https://github.com/chainreactors/spray/releases/latest/download/spray_linux_amd64
2 Basic Scan
spray -u https://target.com \
  -w wordlist.txt \
  -t 50 -ac
3 Scan with Extensions
spray -u https://target.com \
  -w wordlist.txt \
  -e bak,zip,sql,old,tar.gz \
  -ac -o spray.txt
4 Proxy + Custom Headers
spray -u https://target.com \
  -w wordlist.txt \
  -p http://127.0.0.1:8080 \
  -H "Cookie: session=xxx"
5 Option Table
OptionPurpose
-uURL
-wWordlist
-eExtensions
-acAuto-calibration
-tThreads
-pProxy
-HHeaders
-oOutput file
💡 When to use Spray: When ffuf and feroxbuster fail to filter fake responses — Spray learns automatically.

FFUF

King of flexible filtering — Fuzz Faster U Fool

FFUF v2.1+

GoHighly Flexible

Still the strongest in flexible filtering. Supports FUZZ, W1, W2 for multiple sources, plus clusterbomb/pitchfork modes. Best when you need precise control over results.

1 Installation
# via apt
sudo apt install ffuf

# or via go
go install github.com/ffuf/ffuf/v2@latest
2 Basic Scan
ffuf -u https://target.com/FUZZ \
  -w wordlist.txt \
  -fc 404 -t 50 -c \
  -o ffuf.json -of json
3 Keywords + Extensions (Clusterbomb)
ffuf -u https://target.com/FUZZ.EXT \
  -w common.txt:FUZZ \
  -w web-extensions.txt:EXT \
  -mode clusterbomb -fc 404
4 Smart Filtering (size + words + lines)
ffuf -u https://target.com/FUZZ \
  -w wordlist.txt \
  -fs 1234 -fw 50 -fl 10 \
  -fc 404,403 -ac
5 Parameter Discovery (GET + POST)
# GET
ffuf -u "https://target.com/page.php?FUZZ=test" \
  -w burp-parameter-names.txt -fs 0 -ac

# POST
ffuf -u https://target.com/login \
  -X POST -d "user=admin&FUZZ=test" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -w params.txt -fc 200
6 VHost Discovery
ffuf -u https://target.com \
  -H "Host: FUZZ.target.com" \
  -w subdomains.txt \
  -fs 4242 -ac
7 With Proxy + Recursion
ffuf -u https://target.com/FUZZ \
  -w wordlist.txt \
  -x http://127.0.0.1:8080 \
  -recursion -recursion-depth 2 \
  -fc 404
8 Option Table
OptionPurpose
-uURL (contains FUZZ)
-wWordlist (repeatable)
-XHTTP method
-dPOST data
-HHeaders
-fc / -fs / -fw / -flFilter code / size / words / lines
-acAuto-calibrate
-modeclusterbomb / pitchfork / sniper
-xProxy
-recursionAuto-recursion
-o / -ofOutput + format

Gobuster

Classic multi-mode tool (dir/dns/vhost/s3)

Gobuster v3.6+

GoMulti-Mode

Despite newer tools, Gobuster remains especially useful for DNS enumeration and VHost discovery. Stable performance with excellent multi-mode support.

1 Installation
# apt
sudo apt install gobuster

# go install
go install github.com/OJ/gobuster/v3@latest
2 Basic Scan (dir)
gobuster dir -u https://target.com \
  -w wordlist.txt \
  -t 30 -b 404,403 -k
3 Backup Files
gobuster dir -u https://target.com \
  -w CommonBackupFileNames.txt \
  -x bak,old,zip,sql,swp,~,conf,env \
  -t 25 -b 404
4 DNS Subdomain Enum
gobuster dns -d target.com \
  -w subdomains-top1million-5000.txt \
  -t 50 --wildcard -o subs.txt
5 VHost Discovery
gobuster vhost -u http://target.com \
  -w subdomains-top1million-5000.txt \
  --append-domain -t 40
6 Google Cloud Buckets
gobuster s3 -w bucket-names.txt -t 20
7 Option Table
OptionPurpose
-uURL
-wWordlist
-tThreads
-xExtensions
-bExclude status codes
-sShow only specific codes
-kIgnore SSL
-cCookies
-HHeaders

Dirsearch

Python fuzzer with professional reports

Dirsearch v0.4.3+

PythonBeautiful Reports

Though mature, Dirsearch remains useful for its clean HTML reports and ease of use. Modern versions are faster and smarter.

1 Installation
# pip
pip3 install dirsearch

# From source
git clone https://github.com/maurosoria/dirsearch.git
cd dirsearch && pip3 install -r requirements.txt
2 Basic Scan
dirsearch -u https://target.com \
  -e php,html,js,json,txt,bak,old,zip \
  -t 30 --exclude-status 404,403
3 Custom Wordlist
dirsearch -u https://target.com \
  -w /usr/share/seclists/Discovery/Web-Content/raft-medium-directories.txt \
  -e php,html,js
4 Multiple HTTP Methods + Recursion
dirsearch -u https://target.com \
  -m GET,POST -r -R 3 \
  --recursion-status 200,301,302
5 Advanced Exclusions
dirsearch -u https://target.com \
  --exclude-texts "Not Found" \
  --exclude-sizes "0B,123B" \
  --exclude-redirects "https://target.com/404"
6 HTML / JSON Reports
dirsearch -u https://target.com \
  -e php,html \
  --format html \
  -o report.html
7 Proxy + Random Agent
dirsearch -u https://target.com \
  --proxy http://127.0.0.1:8080 \
  --delay 0.5 -t 10 \
  --random-agent
8 Option Table
OptionPurpose
-uURL
-eExtensions
-wWordlist
-tThreads
-mHTTP methods
-r / -RAuto-recursion / depth
--exclude-statusExclude status codes
--exclude-sizesExclude sizes
--exclude-textsExclude text patterns
--formatReport format

x8

Fastest hidden parameter discovery

x8 v3.0+

RustParameter Discovery

The modern replacement for Arjun — dozens of times faster, using value reflection + chunking. Discovers parameters in GET, POST, JSON, and headers with intelligence.

1 Installation
# Cargo
cargo install x8

# Or download binary
wget https://github.com/Sh1Yo/x8/releases/latest/download/x8-linux-amd64
2 Basic GET Parameter Scan
x8 -u "https://target.com/page" \
  -w params.txt \
  --reflected-only -c 50
3 POST + JSON Scan
x8 -u "https://api.target.com/v1/user" \
  -X POST \
  -b "session=abc" \
  -H "Content-Type: application/json" \
  -w params.txt
4 Multi-Block (Bypass)
x8 -u "https://target.com/api" \
  -w params.txt \
  --reflected-only \
  --learn-requests 10
5 From URL File
cat urls.txt | x8 -w params.txt \
  --reflected-only -o found-params.txt
6 Option Table
OptionPurpose
-uURL
-wParameter wordlist
-XHTTP method
-bCookies
-HHeaders
--reflected-onlyReflected parameters only
-cConcurrency
--learn-requestsLearning requests
💡 Best: x8 is the new standard for parameter discovery — lower memory than Arjun and drastically faster.

Kiterunner

The strongest API endpoint discovery

Kiterunner v1.0.2+

GoAPI Discovery

From the Assetnote team, purpose-built for discovering REST API routes. Uses smart wordlists that understand path structure — far faster than any traditional fuzzer on APIs.

1 Installation
# Download binary
wget https://github.com/assetnote/kiterunner/releases/latest/download/kr_linux_amd64
chmod +x kr_linux_amd64 && sudo mv kr_linux_amd64 /usr/local/bin/kr

# Download wordlists (.kite)
wget https://wordlists-cdn.assetnote.io/data/kiterunner/routes-large.kite.tar.gz
tar -xzf routes-large.kite.tar.gz
2 Basic API Scan
kr scan https://api.target.com \
  -w routes-large.kite \
  -x 20 -o api-scan.txt
3 Single Wordlist Brute
kr brute https://api.target.com \
  -w routes.kite \
  -A=apiroutes-240528 \
  -x 15
4 With Auth + Headers
kr scan https://api.target.com \
  -w routes.kite \
  -H "Authorization: Bearer xxx" \
  --fail-status-codes 404,400
5 Specific Values + JSON Output
kr scan https://api.target.com \
  -w routes.kite \
  -j -o api.json
6 Option Table
OptionPurpose
scanFast scan mode
bruteSingle wordlist mode
-w.kite wordlist
-xConcurrency
-HHeaders
--fail-status-codesCodes treated as failures
-jJSON output
-AUse Assetnote ready-made wordlist
💡 Best for: bug bounty on APIs (HackerOne, Bugcrowd). Don't use on regular websites — ffuf/feroxbuster are better for those.

No static wordlist needed! It dynamically builds candidate names from the domain (domain.com, www.domain.com, domain-backup, etc.) and discovers backup files in all their forms.

3 Specific Extensions + Output

  -ext zip,tar.gz,sql,rar,7z,bak,backup \
  -o backups.txt
4 Multiple Methods + Threads
fuzzuli -url https://target.com \
  -method get,head \
  -t 30 \
  -ac
5 Status Code Filtering
fuzzuli -url https://target.com \
  -ext zip,sql,tar.gz \
  -s 200,301,302
6 Option Table
OptionPurpose

-extExtensions

Katana

Modern crawler with headless + JS parsing

Katana v1.1+

GoWeb Crawler

From ProjectDiscovery, an advanced crawler using headless Chromium + JS parsing + form filling. Far superior to hakrawler and gospider.

1 Installation
# go install

# or via apt
sudo apt install katana
2 Basic Crawl
katana -u https://target.com \
  -d 3 -silent -o urls.txt
3 Deep Crawl with JS + Forms
katana -u https://target.com \
  -jc -kf all \
  -aff \
  -d 5 -silent
-jc JS crawling · -kf known files · -aff auto form fill
4 Headless Mode (JS-heavy sites)
katana -u https://target.com \
  -headless -no-sandbox \
  -jc -d 3
5 From URL List
cat live.txt | katana -list /dev/stdin -jc -silent -o urls.txt
6 Proxy + Filters
katana -u https://target.com \
  -proxy http://127.0.0.1:8080 \
  -ef woff,css,png,jpg,svg \
  -fs 'regex:\.(css|js|woff)$'
7 Option Table

Dalfox

Fastest, most accurate XSS automation

Dalfox v2.9+

GoXSS Scanner

The modern replacement for XSStrike. Supports DOM XSS, blind XSS, parameter mining, and WAF bypass using advanced techniques to find real XSS.

  --deep-domxss \
